# Escape Room · Protocolo CERBERUS

Proyecto de Programación para Web (11-5) hecho con React y Vite.

## Cómo ejecutarlo

```
npm install
npm run dev
```

Después se abre http://localhost:5173 en el navegador.

## Estructura

- `src/App.jsx`: estados del juego (useState) y cambio entre pantallas.
- `src/components/`: componentes de la interfaz.
- `src/data/`: arreglo de retos y textos de la historia.
